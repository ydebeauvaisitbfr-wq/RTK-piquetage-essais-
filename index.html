Assistant Connexion « FT232R USB UART » & Centipede

Solution A — Pont Windows « FT232R USB UART + Centipede » Sans blocage navigateur

Si votre navigateur ne trouve pas FT232R USB UART : téléchargez et double-cliquez sur ce fichier .bat. Il ouvre le port USB/COM de l'antenne, se connecte à caster.centipede.fr:2101, envoie les corrections RTCM3 à l'antenne et ouvre l'application sur http://localhost:8765.

Solution B — Pilote Direct WebUSB FT232R (0x0403) & Port COM

• Pilote WebUSB FT232R : dialogue directement avec la puce FTDI (VID 0403 / PID 6001) sur Android OTG ou Windows (si le pilote WinUSB est actif).
• Port Série COM : si votre FT232R apparaît dans Windows sous Ports (COM et LPT) → USB Serial Port (COMx).

Votre antenne s'appelle « FT232R USB UART » dans Windows ?

Quand Windows affiche le nom « FT232R USB UART » dans Autres périphériques (au lieu de USB Serial Port COMx), cela signifie que le pilote FTDI VCP n'est pas encore activé : allez dans Paramètres Windows → Windows Update → Options avancées → Mises à jour facultatives → Pilotes et cochez FTDI - Ports (ou utilisez Pilote WebUSB FT232R).
