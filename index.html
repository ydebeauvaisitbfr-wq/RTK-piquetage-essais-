Connexion de votre Antenne GPS / RTK

Choisissez le mode de liaison de votre antenne centimétrique pour que le navigateur affiche la fenêtre d'autorisation :

1. GPS Appareil / Antenne via NTRIP (Android, iOS, Windows) Prêt

Déclenche la demande d'autorisation de localisation du navigateur. Idéal si votre antenne est connectée via Bluetooth GNSS, SW Maps ou Lefebure NTRIP sur smartphone/tablette.

2. Port Série USB ou Bluetooth COM (Trames NMEA 0183)

Ouvre le sélecteur de port de Chrome/Edge pour choisir votre récepteur RTK (u-blox F9P, Emlid Reach, Septentrio, Trimble...) en USB ou Bluetooth SPP.

3. Recherche Bluetooth directe (BLE)

Demande au navigateur de scanner les antennes Bluetooth Low Energy (BLE UART / Location Service) à proximité.
