Tutoriel SW Maps & Mock Location

Étape 1 : Activer le mode Développeur Android

  • Allez dans les Paramètres du téléphone > À propos du téléphone.
  • Tapotez 7 fois de suite sur la ligne Numéro de build (ou Version de l'OS) jusqu'à voir "Vous êtes désormais développeur".

Étape 2 : Configurer "Position Fictive" (Mock Location)

  • Retournez dans les Paramètres > Options pour les développeurs.
  • Cherchez Sélectionner l'application de position fictive.
  • Choisissez SW Maps.

Étape 3 : Désactiver le "Faux GPS" Google (Crucial)

C'est ce réglage qui empêche d'avoir la précision centimétrique sur le web :

  • Allez dans les Paramètres > Position (Localisation) > Services de localisation.
  • Désactivez Précision de la localisation Google.
  • Désactivez aussi Recherche Wi-Fi et Recherche Bluetooth.

Étape 4 : Lancer SW Maps

  • Ouvrez SW Maps. Allez dans USB GNSS, connectez l'antenne et cochez « Enable Mock Location ».
  • Allez dans NTRIP Client, connectez-vous à Centipede pour obtenir le RTK FIX.
  • Revenez sur cette page Web et cliquez sur Démarrer la réception GPS !
